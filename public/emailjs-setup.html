EmailJS Setup Guide for Abdul Rehman's Portfolio

This guide will walk you through setting up EmailJS so that you can receive emails when someone fills out the contact form on your portfolio website.

Your Details

Email: shahidabdulrehman706@gmail.com

You'll need to use this email to create your EmailJS account.

Step 1: Create an EmailJS Account

  1. Go to https://www.emailjs.com/
  2. Click "Sign Up Free" button
  3. Sign up using your email shahidabdulrehman706@gmail.com
  4. Complete the registration process

Step 2: Create an Email Service

  1. After logging in, go to the "Email Services" section
  2. Click the "Add New Service" button
  3. Select "Gmail" as your service provider
  4. Connect your Gmail account shahidabdulrehman706@gmail.com
  5. Name your service (e.g., "portfolio_service")
  6. Click "Create Service" to finalize
  7. Important: Write down the Service ID (looks like service_xxxxxxx)

Step 3: Create an Email Template

  1. Go to the "Email Templates" section
  2. Click "Create New Template"
  3. Fill in the details:
    • Template Name: "Contact Form"
    • Subject: "New contact form submission from {{from_name}}"
  4. Use this content for your email template:
    5. You received a new message from your portfolio contact form:

Name: {{from_name}}
Email: {{from_email}}
Subject: {{subject}}

Message:
{{message}}

--
This email was sent from your portfolio contact form.
  5. Click "Save" to create your template
  6. Important: Write down the Template ID (looks like template_xxxxxxx)

Step 4: Get Your User ID (Public Key)

  1. Go to the "Account" section
  2. Click on "API Keys"
  3. Find your Public Key (starts with "user_" or a similar prefix)
  4. Important: Write down this Public Key

Step 5: Update Your Code

  1. Open the file src/components/sections/Contact.tsx in your project
  2. Look for these lines:
    3. const EMAILJS_SERVICE_ID = 'service_portfolio';
const EMAILJS_TEMPLATE_ID = 'template_contact';
const EMAILJS_USER_ID = 'YOUR_USER_ID';
  3. Replace these values with the ones you collected:
    • Replace 'service_portfolio' with your actual Service ID (like 'service_abcdef')
    • Replace 'template_contact' with your actual Template ID (like 'template_xyz123')
    • Replace 'YOUR_USER_ID' with your actual Public Key

Final Step: Test Your Form

  1. Deploy your website
  2. Fill out the contact form on your website
  3. Submit the form
  4. Check your email shahidabdulrehman706@gmail.com to see if you received the test message

Troubleshooting

If you don't receive emails:

  • Check your spam folder
  • Verify that all IDs are correctly entered in the code
  • Make sure your EmailJS account is properly set up
  • Check if you have exceeded the free tier limits (200 emails per month)
